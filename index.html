CSV import accepts files exported by this app — Google Contacts CSV or Excel (CSV). Duplicate phone numbers are skipped automatically. Imported records are marked as older so today's export won't repeat them.

How it works

  • Class A/B/C — rate every customer by phone pickup: A picks up easily, B sometimes, C rarely or never. Filter the list with the chips.
  • Contact name format — Google Contacts name is Class - Name - Address - Area, e.g. A - Pari Shaw - Khaitan Traders Opposite - K.Para; the auto-detected GPS address goes to the Address field.
  • Auto-location — tap Add and your exact GPS spot is captured automatically (or use the button).
  • Open in Maps — one tap opens Google Maps with a pin at the spot.
  • Call / WhatsApp — reach the customer directly.
  • Offline-first — internet is needed only for Maps, GPS and reverse address lookup.
